# Libras-il

Projeto acadêmico desenvolvido para apresentar informações sobre a Língua Brasileira de Sinais (Libras), abordando sua importância para a acessibilidade e a inclusão.

## Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização e layout |
| JavaScript | Interatividade e validação do formulário |

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| Navegação | Acesso às páginas do site |
| Conteúdo informativo | Informações sobre Libras |
| Formulário de contato | Preenchimento e validação de dados |
| Interatividade | Mensagens exibidas com JavaScript |

## Como executar

1. Clone o repositório ou baixe os arquivos.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

## Objetivo

Praticar os fundamentos do desenvolvimento web utilizando HTML, CSS e JavaScript.
